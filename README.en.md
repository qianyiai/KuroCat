## 🤖 AI Companion &amp; MCP Cat Studio

KuroCat ships a zero-dependency **Stdio** and local **Streamable HTTP (`127.0.0.1:27420`)** MCP Server inside the single binary:

1. Launch KuroCat, right-click the pet → enable **MCP Extension** → click **Copy MCP Config** (or **Send to AI Auto-Setup**).
2. Paste into **Claude Desktop / Cursor / Antigravity / Windsurf / Cline** and prompt in natural language:

> 💬 *"Look at this photo of my calico cat — use KuroCat MCP to sculpt a matching 3D desktop pet with its ear shape and spots, then switch to it!"*  
> 💬 *"Scale KuroCat to 85%, switch to the 108-key viewer perspective, and hide floating key bubbles."*

<details>
<summary>📋 <b>Show Stdio / HTTP JSON Config &amp; All 10 Built-in MCP Tools</b></summary>

<br />

**Option A: Stdio (universal MCP client support)**
```json
{
  "mcpServers": {
    "kurocat": {
      "command": "C:\\Users\\<YOUR_USER>\\AppData\\Local\\KuroCat\\KuroCat.exe",
      "args": ["--mcp"]
    }
  }
}
```

**Option B: Local Streamable HTTP (while KuroCat is running)**
```json
{
  "mcpServers": {
    "kurocat": {
      "url": "http://127.0.0.1:27420/mcp"
    }
  }
}
```

| Tool | Description |
| --- | --- |
| `list_cats` | List all built-in and custom skins plus the active character |
| `get_cat_schema` | Fetch full fur patterns, 16-spot coordinates &amp; 7 2D/3D contour parameters |
| `upsert_cat` | Create or overwrite a custom cat with 0.4s live hot-reload |
| `patch_cat` | Fine-tune an existing or built-in cat partially |
| `switch_cat` | Immediately switch the active desktop pet by ID |
| `delete_cat` | Remove a custom cat (or reset an overridden built-in skin) |
| `get_settings` / `update_settings` | Read or update scale, keyboard layout, bubbles, purring, click-through &amp; autostart |
| `set_agent_status` | Sync AI coding agent state (thinking, coding, running command, waiting, error, done) |
| `trigger_action` | Trigger interactive desktop animations (pet, happy, cross, sleep) |

Custom skins are stored in `%APPDATA%\kuro-cat-pet\cats.json` (Windows) or `~/Library/Application Support/kuro-cat-pet/cats.json` (macOS) with live hot-reload.

</details>

<details>
<summary>🛠️ <b>Developer Guide: Build from Source &amp; macOS Release Signing</b></summary>

<br />

Prerequisites: Windows 10/11 or macOS 11+, Node.js 18+, Rust (`cargo`).

```bash
git clone https://github.com/qianyiai/KuroCat.git
cd kurocat
npm install
npm run tauri:dev      # Local hot-reload dev
npm run tauri:build    # Production release bundle
```

**macOS Release Signing (optional — preserves Accessibility permissions across updates)**:

```bash
scripts/macos-codesign.sh create-cert /path/outside/repo/kurocat-signing
gh secret set MACOS_SIGNING_CERT_P12_BASE64 < /path/outside/repo/kurocat-signing/kurocat-signing.p12.base64
gh secret set MACOS_SIGNING_CERT_PASSWORD < /path/outside/repo/kurocat-signing/kurocat-signing.password
```
