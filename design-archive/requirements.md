# 需求与设计方向

## 已确定的角色范围

14 个角色：02（Zero Two）、雷电将军、八重神子、芙宁娜、仪玄、喜多川海梦、琉璃川椿、薇尔莉特、樱岛麻衣、雷姆、约尔·福杰、C.C.、玛奇玛、爱蜜莉亚。

琉璃川椿作品由用户确认：女仆教育／没落贵族。02 在先前澄清中按《DARLING in the FRANXX》的 Zero Two 记录。制作中应以角色参考核对外观，不用通用配色替代角色辨识度。

## 主款着装决定（2026-11-24）

用户最新决定：“仪玄使用墨形影踪，其他人物使用最热门的着装”。同时沿用“优先游戏、动漫内的，动作要符合设定”。仪玄主款已经明确指定；其余主款按原作主形象、传播辨识度与常见代表造型选定。尚无覆盖全部角色、口径一致的着装人气统计，以下不是经投票验证的热度排名。

| 角色 | 本轮主款 | 制作约束 |
| --- | --- | --- |
| 02 | 动画经典红色制服裙 | 区分制服裙与红色驾驶服，不混合剪裁 |
| 雷电将军 | 游戏经典紫色默认服装 | 以官方立绘/模型核对，不混用同人改装 |
| 八重神子 | 游戏红白巫女默认服装 | 保留原版头饰、袖型和服装层次 |
| 芙宁娜 | 游戏经典蓝色礼服、礼帽造型 | 发型、配色与形态成套核对，不拼接两种形态 |
| 仪玄 | 官方衣装「墨形影踪」（Trails of Ink） | 以官方衣装和游戏画面为准；不采用黄色默认装或自创黑金露腰装作为主款 |
| 喜多川海梦 | 动画经典校服 | 保留既定正片服装范围；黑江雫为首个Cos候选，不因此删除其他草稿 |
| 琉璃川椿 | 作品经典黑白女仆装 | 先用原作者角色图校准外貌与服装，不以现有AI草稿作为原作证据 |
| 薇尔莉特 | 动画蓝色短外套＋白色长裙＋绿宝石胸针 | 保留义手结构与自动手记人偶职业形象 |

| 约尔·福杰 | 动画「荆棘公主」黑色礼服 | 区分战斗时的利落与日常交流时的拘谨，避免持续笨拙化 |
| C.C. | 动画经典白色拘束服 | 使用原作结构；以从容、慵懒和淡淡调侃为表现方向 |
| 玛奇玛 | 动画公安白衬衫＋黑领带＋黑长裤 | 强调平静、控制感和环纹眼，不套通用可爱表情 |

着装主款不等于角色包或图集已更新。旧图继续作为待核对草稿保存，不因本决定自动验收。动作须先核对官方演示、动画正片中的性格和习惯，再转译为键鼠互动；未出现在原作中的打字等动作必须标为桌宠改编，不能宣称原作既有动作。同人图只辅助参考画法、构图和表情，不覆盖原作着装结构。

## 动作设计方向（建议，待视觉验收）

用户确定的原则是“要有角色的灵魂”；下表把原则具体化为后续制作方向，不视为每项动作均已获用户单独确认或已实现。

| 角色 | 待机／输入方向 | 互动方向 |
| --- | --- | --- |
| 02 | 前倾、轻快而有挑衅感的敲击 | 歪头、俏皮招呼 |
| 雷电将军 | 端正、克制、节奏稳定 | 短暂停顿与审视 |
| 八重神子 | 从容、慵懒，输入带停顿 | 侧目、掩嘴轻笑 |
| 芙宁娜 | 戏剧化姿态，活泼输入 | 谢幕、期待回应 |
| 仪玄 | 松弛沉稳、动作干净 | 舒展与淡定回应 |
| 喜多川海梦 | 热情明快，兴奋时前倾 | 展示服装；Cos 时兼顾扮演姿态和本人的反应 |
| 琉璃川椿 | 姿态与服饰先按作品参考复核 | 暂不凭未核对的性格设定固化动作 |
| 薇尔莉特 | 精确、有秩序的打字 | 整理袖口、温和停顿 |
| 樱岛麻衣 | 冷静利落，小幅度表情 | 侧目、轻微吐槽反应 |
| 雷姆 | 认真柔和、均匀输入 | 关切提醒、轻轻点头 |
| 约尔·福杰 | 礼貌略拘谨，偶有用力过猛的反差 | 害羞、整理手套 |
| C.C. | 懒散从容，动作幅度小 | 托腮、淡淡侧目 |
| 玛奇玛 | 稳定、克制，视线有压迫感 | 缓慢微笑、平静注视 |
| 爱蜜莉亚 | 温柔认真、轻快但不过度夸张 | 鼓励、轻轻挥手 |

动作差异必须体现在姿态、表情、时序和交互反馈中；仅改播放速度、颜色或台词不足以满足要求。

## 共通状态与验收

- 支持待机、打字、鼠标、互动、休息和密码隐私状态；触发与退出过程自然。
- 输入动作与真实键鼠状态衔接；服装切换保留角色选择及合理状态。
- 防窥状态沿用官方隐私行为，隐藏敏感按键／气泡。
- 人物轮廓、发色、服装和表情可辨识；透明边缘、手部、服装对齐须检查。
- 在确定的加载机制中实际完成导入、列出、切换、重启保留和升级兼容验证，才可称“可用皮肤”。
- 当前未有用户批准的最终角色包格式、统一画布规格或完整动作帧数；旧图集规格只是原型事实。
