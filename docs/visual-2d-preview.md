# 2D 真实视觉验收页

本页只运行前端源码，使用真实 PNG 和 Canvas。不会启动 Tauri、连接 MCP、导入包或写入应用数据。2026-11-24 已用现有 Edge 实际打开页面、操作并检查截图；本页不承担桌面系统输入/穿透/原生菜单/真实OBS验收；原生证据见character-system-status.md。

## 打开与启动

预览服务地址：<http://127.0.0.1:1422/visual-2d.html>，仅本机可访问。需要保持启动命令所在进程运行；停止时按 Ctrl+C。

在项目根目录运行（复用此前核验的旧依赖，不安装环境）：

```powershell
node scripts/preview-character-2d.mjs '<已有兼容node_modules的绝对路径>'
```

也可传其他已有兼容 Vite 的 node_modules 绝对路径。端口占用会直接报错，不自动切换或结束其他进程。默认沙箱浏览器/套接字不可用时，本轮使用了获自动审核许可的沙箱外现有 Edge 和本机服务，没有安装浏览器或生成 EXE。

## 不读代码的验收步骤

1. 打开页面。左为固定 Git 基线 20be633 原版，中为共享播放器+外置大肥鱼协议，右为借用相同 PNG 的沉静动作示例。先检查身体、眼睛、发丝遮挡、袖口、键鼠和透明边缘；第三栏不是新人物资产。
2. 点“连续打字”，观察手部拍键、身体弹动与目光；点“鼠标＋键盘＋尾巴”，应见鼠标手、键盘手和尾巴并行，右栏无尾。点“释放所有输入”后不再保持按键。
3. 点“往返抚摸”，左右两栏应开心举手，右栏应表现自己的倾斜/害羞反应。也可在画布人物脸部往返移动鼠标：静止悬停不增加能量，按住鼠标拖动不算抚摸。画布内的动作同步到三栏。
4. 在动作中点“隐私模式”，应闭眼捂眼、隐藏按键提示；点“匿名输入反馈”观察捂眼时轻微反馈。退出后新版不补播旧输入。原版可能残留抚摸能量，这是已知的旧策略差异。
5. 轮流选 65/108 键、两种朝向和 60%/100%/150% 缩放，检查裁切及手/键帽位置。第三栏改成“大肥鱼动作”，组合输入时应恢复尾巴能力，模拟人物/服装播放器替换；不代表原生激活持久化已通过。
6. 点“暂停”检查静帧，“单步”每次前进 1/60 秒；“重置”重载页面，重置模拟时间和各栏随机种子。点击画布后可用真实键盘和鼠标按钮；Tab 保留正常焦点导航，页面失焦会释放输入。

## 基线、重现与限制

启动器通过只读 `git show 20be633...:src/...` 取原版 CatEngine/DaFeiYuRenderer，以 Vite 虚拟模块转译，不覆盖工作区源码。其他共用的键盘/猫咪辅助模块仍取工作区，不是完整原版发行包快照。三个引擎接受相同事件；预览通过测试适配访问引擎的 update/render 和坐标变换，不调用桌面入口。这个接口若重构，需要同步维护预览。

固定步长、独立随机种子与模拟时钟便于在同一模拟时间重现。新旧随机调用次数、反应池和隐私清理有差异，不能把逐像素相等作为验收条件。这里的 embedded 缩放保留原引擎策略，150% 并不是桌面窗口物理尺寸的承诺。真实 PNG 全部解码后才标记就绪。

实际截图发现并修复：默认大肥鱼单次抚摸反应结束后提前放手。现在只含 cheer 的性格池会在抚摸能量足够时保持举手；其他性格仍按自己的反应动作。还修复了预览暂停时 resize 清空 Canvas 的问题。
